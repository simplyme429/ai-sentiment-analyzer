AI Sentiment Analysis Web App

A simple and useful web app that analyzes whether text (reviews, tweets, comments) is "Positive", "Negative", or "Neutral".

Features
- Real-time sentiment analysis
- Upload multiple reviews using CSV file
- Shows nice charts
- Download results

Tech Stack
- Python
- Streamlit
- TextBlob

How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
